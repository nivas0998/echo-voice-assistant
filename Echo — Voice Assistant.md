# Echo — Voice Assistant

- [x] **Voice-first dashboard**
  - Create a polished responsive web app centered on an AI-powered virtual assistant that understands voice commands and helps users perform everyday tasks.
  - Include a prominent microphone control for starting, pausing, and ending a voice interaction.
  - Provide accessible interaction states, readable hierarchy, and keyboard-friendly controls.

- [x] **Live assistant interaction**
  - Show clear visual feedback while the assistant is hearing or processing input.
  - Display assistant states including ready, listening, thinking, responding, and unavailable.
  - Present the user request and assistant result in an easy-to-scan conversational response area.

- [x] **Everyday task discovery and history**
  - Offer suggested everyday actions that help users quickly begin common assistant tasks.
  - Include a recent activity feed for reviewing prior requests and outcomes.
  - Optimize the dashboard layout for both desktop and mobile interaction.
